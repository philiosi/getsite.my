# Motion graphics samples

Painter hero motion-graphics samples for Yoon Seo-hyun (sample persona).
Open each HTML file directly in a browser; assets are inlined.

- `hwaga-hieoro-mosyeongeuraepig-saempeul.html` — Hero 5 styles, one screen, button switching:
  1. Living canvas, 2. Pixel transition, 3. Work slideshow, 4. Light cycle, 5. Parallax gallery.
- `hwaga-hieoro-mosyeongeuraepig-saempeul-2.html` — Second set, 7 tabs:
  1. Watercolor bleed mask, 2. Tile flip mosaic, 3. Spring gallery wall,
  4. Scroll film, 5. Exhibition-room camera move, 6. Cursor brush, 7. MP4 cinematic.
  The MP4 tab was re-rendered with Remotion (same shots, 1280x720, 30fps, 10s, silent);
  the Remotion source lives in `~/workspace/remotion-scratch/` on the Muse VM
  (re-render needs `npm install` there) and is not part of this repo.

All artwork images are sample/generated images, not real artist works.
