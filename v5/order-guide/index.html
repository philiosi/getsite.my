주문 후, 이렇게
진행됩니다

접수 폼을 보내고 나서부터 최종 사이트가 완성될 때까지의 전체 7단계입니다. 각 단계에서 어떤 메일과 링크가 오가는지, 고객님이 하실 일과 운영자가 하는 일을 함께 정리했습니다.

01주문 접수 02접수 안내 메일 03브리프 정리 04샘플 제작 05샘플 완료 메일 06확인 · 수정 07최종 제작

진행 과정에서 메일은 두 번 발송됩니다. 접수 직후의 접수 안내 메일(2단계)과 샘플이 완성됐을 때의 샘플 제작 완료 메일(5단계)입니다. 두 메일 모두 접수할 때 입력하신 이메일 주소로 갑니다.

  1. 1

    주문 접수

    시작

    getsite.my 접수 폼에 만들고 싶은 사이트의 내용을 적어 보내 주시면 접수가 완료되고, 주문마다 의뢰번호가 하나씩 발급됩니다. 이후 모든 안내는 이 의뢰번호를 기준으로 진행됩니다.

    • 접수 폼 입력 내용
    • 의뢰번호 발급

    고객님이 할 일

    • 접수 폼에 사이트명, 사이트의 목적, 원하는 샘플과 스타일을 적습니다.
    • 필요한 섹션과 참고자료(링크·파일·메모)를 함께 보냅니다.
    • 접수 후 발급되는 의뢰번호를 확인합니다.

    운영자가 하는 일

    • 접수된 주문과 의뢰번호를 확인합니다.
    • 다음 단계인 접수 안내 메일 발송으로 이어집니다.

  2. 전체 의뢰 코드 · 진행 조회 안내

    꼭 확인

    주문 진행을 조회할 때는 1단계에서 발급된 짧은 번호가 아니라, 뒤에 20자가 더 붙은 전체 의뢰 코드가 필요합니다. 짧은 번호만 넣으면 조회가 되지 않습니다.

    WO-2026-1234-a1B2c3D4e5F6g7H8i9J0 (예시)

    알아 두실 점

    • 뒤의 20자는 무작위로 만들어져 추측할 수 없습니다. 사실상 이 주문의 비밀번호 역할을 합니다.
    • 전체 의뢰 코드는 접수 완료 화면과 접수 안내 메일(2단계)에서 받으실 수 있습니다.
    • 진행 조회 시에는 전체 코드를 빠짐없이 그대로 입력해 주세요.

    전체 의뢰 코드를 알면 누구나 이 주문의 진행 상황을 볼 수 있습니다. 다른 사람에게 공유하지 마세요.

  3. 2

    접수 안내 메일 발송

    메일 발송

    접수가 확인되면 접수 내역이 담긴 메일이 고객님과 운영자에게 함께 발송됩니다. 내가 보낸 내용이 제대로 접수됐는지 메일 한 통으로 확인할 수 있습니다.

    • 접수 안내 메일
    • Drive 폴더 링크
    • 메일 샘플 보기

    메일에 담기는 내용

    • 의뢰번호
    • 사이트명
    • 사이트의 목적
    • 선택한 샘플
    • 섹션 구성
    • 견적
    • 보내 주신 참고자료
    • 자료를 올릴 Drive 폴더 링크
    • 앞으로의 다음 단계 안내
    접수 안내 메일 샘플 보기

    예시 주문 WO-2026-6934(다올 그림 스튜디오) 기준으로 채운 메일입니다. 샘플 보기와 진행 조회 버튼은 이 예시 주문의 실제 페이지로 연결되고, 전체 의뢰 코드 표기와 Drive 폴더는 예시 값입니다.

    고객님이 할 일

    • 메일에서 접수 내역이 폼에 적은 내용과 같은지 확인합니다.
    • 추가로 쓸 사진이나 자료가 있으면 메일 안의 Drive 폴더 링크에 올려 주세요.

    운영자가 하는 일

    • 같은 메일을 받아 접수 내용을 확인합니다.
    • 접수 내용을 바탕으로 브리프 정리를 시작합니다.
  4. 3

    브리프 정리

    운영자 작업

    접수 폼에 적어 주신 내용을 제작 기준으로 정리한 브리프를 만듭니다. 사이트의 목적, 섹션 구성, 원하는 분위기와 참고자료를 샘플 제작에 바로 쓸 수 있는 형태로 정리하는 단계입니다.

    • 브리프 문서

    고객님이 할 일

    따로 하실 일은 없습니다. 추가로 전하고 싶은 내용이 생기면 Drive 폴더나 메일 회신으로 알려 주세요.

    운영자가 하는 일

    • 접수 내용을 항목별로 정리해 브리프를 작성합니다.
    • 요청 항목을 어떻게 디자인에 반영할지 기준을 세웁니다.

  5. 자료 업로드 가이드

    자료 준비

    최종 제작에 필요한 자료는 주문 전용 Drive 폴더에 올려 주세요. 어떤 자료가 필요하고, 어떻게 올리는지 정리했습니다.

    필요한 자료

    • 로고 파일
    • 사진 원본
    • 소개 · 작업 설명 글
    • 참고 사이트 링크
    • SNS 링크

    올리는 방법

    1. 접수 안내 메일(2단계)에 있는 Drive 폴더 링크를 엽니다.
    2. 올릴 파일을 폴더 화면에 드래그해서 놓으면 업로드됩니다.
    3. 파일 이름은 알아보기 쉽게 적어 주세요. (예: 로고.png, 작품1.jpg)

    사진은 줄이거나 압축하지 않은 원본 고화질로 보내 주세요. 화질이 좋아야 사이트에서도 선명하게 쓸 수 있습니다.

  6. 4

    샘플 제작

    운영자 작업

    브리프를 기준으로 샘플 홈페이지를 만듭니다. 실제 사이트와 같은 형태로 만들어, 완성된 모습을 미리 보고 판단할 수 있게 하는 단계입니다.

    • 샘플 홈페이지 제작

    고객님이 할 일

    따로 하실 일은 없습니다. 샘플이 완성되면 다음 단계의 메일로 알려 드립니다.

    운영자가 하는 일

    • 브리프 기준으로 샘플 홈페이지를 제작합니다.
    • 요청 항목이 각각 어떻게 반영됐는지 설명을 함께 준비합니다.
  7. 5

    샘플 제작 완료 메일 발송

    메일 발송

    샘플이 완성되면 샘플 링크가 담긴 메일이 고객님에게 발송됩니다. 메일에는 의뢰 내용을 어떻게 반영했는지를 요청 항목별로 설명한 내용도 함께 들어갑니다.

    • 샘플 제작 완료 메일
    • 샘플 보기 링크
    • 요청 항목별 반영 설명
    • 메일 샘플 보기

    메일에 담기는 내용

    • 샘플 페이지 링크
    • 디자인 컨셉 요약
    • 요청 → 정리·해석 → 디자인 반영 설명
    • 반영하지 못한 항목과 그 이유
    • 확인 후 다음 단계 안내
    샘플 제작 완료 메일 샘플 보기

    예시 주문 WO-2026-6934(다올 그림 스튜디오) 기준으로 채운 메일입니다. 샘플 보기와 진행 조회 버튼은 이 예시 주문의 실제 페이지로 연결되고, 전체 의뢰 코드 표기와 Drive 폴더는 예시 값입니다.

    고객님이 할 일

    • 메일의 링크를 열어 샘플을 직접 확인합니다.
    • 반영 설명을 읽고, 요청한 내용과 다르게 된 부분이 없는지 봅니다.

    운영자가 하는 일

    • 샘플 링크와 항목별 반영 설명을 메일로 보냅니다.
    • 고객님의 확인과 수정 요청을 기다립니다.

  8. 결제 안내

    착수금 50% · 잔금 50%

    샘플을 확인하신 뒤 최종 제작을 진행하시려면 결제가 필요합니다. 결제는 계약금 50% + 잔금 50%로 두 번에 나눠 진행되며, 금액은 VAT 별도입니다.

    착수금 50% 입금→ 최종 제작 시작→ 완성 · 확인→ 잔금 50% 입금→ 배포 · 인계

    고객님이 할 일

    • 샘플을 확인하고 최종 제작 진행 여부를 알려 주세요.
    • 착수금 50%를 입금해 주시면 최종 제작을 시작합니다.
    • 완성된 사이트를 확인하신 뒤 잔금 50%를 입금해 주세요.

    운영자가 하는 일

    • 착수금이 확인되면 최종 제작을 시작합니다.
    • 완성 후 사이트를 확인하실 수 있게 안내합니다.
    • 잔금이 확인되면 사이트를 배포하고 인계합니다.

    입금 계좌는 확정 후 안내드립니다. 안내받으신 계좌로만 입금해 주세요.

  9. 6

    고객 확인 · 수정

    함께 확인

    샘플을 보시고 바꾸고 싶은 부분을 알려 주시는 단계입니다. 색이나 문구, 구성처럼 눈에 보이는 것부터, 실제 사진·자료로 교체할 부분까지 이 단계에서 정리합니다.

    • 수정 요청
    • 실제 사진 · 자료

    고객님이 할 일

    • 샘플을 보고 수정하고 싶은 부분을 알려 주세요.
    • 샘플용 이미지 대신 들어갈 실제 사진이나 자료가 있으면 보내 주세요.
    • 방향이 확정되면 알려 주세요.

    운영자가 하는 일

    • 수정 요청을 확인하고 샘플에 반영합니다.
    • 확정된 내용을 최종 제작 기준으로 정리합니다.
  10. 7

    최종 제작

    완성

    샘플이 확정되면 이를 기준으로 최종 사이트를 제작하고 배포합니다. 완성된 사이트는 실제 주소로 열 수 있는 상태로 전달됩니다.

    • 최종 사이트

    고객님이 할 일

    • 완성된 최종 사이트를 확인합니다.

    운영자가 하는 일

    • 확정된 샘플을 기준으로 최종 사이트를 제작합니다.
    • 사이트를 배포해 실제로 접속할 수 있게 합니다.

메일이 오지 않는다면

접수 안내 메일과 샘플 제작 완료 메일은 접수할 때 입력하신 이메일 주소로 발송됩니다. 메일이 보이지 않으면 먼저 스팸함을 확인해 주세요. 그래도 찾을 수 없으면 아래 문의처로 의뢰번호와 함께 알려 주시면 확인해 드립니다.
