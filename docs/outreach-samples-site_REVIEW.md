## 4개 공통

### Critical
1. **신청 버튼에 `?sample=`이 없다.** 4개 모두 `https://getsite-my.web.app/#start`로 간다(todos:772, blessing:897, hansol:594, romi:645). 지난번에 만든 `?sample=outreach-<slug>#start` 연결이 쓰이지 않아, 사장님이 눌러도 빈 신청 폼이 열린다. → 각 링크를 `/?sample=outreach-<slug>#start`로.
2. **검색 노출 차단이 없다.** `robots` 메타·`X-Robots-Tag`·`robots.txt` 모두 없음. 실제 상호 + 예시 가격·후기가 검색에 잡힐 수 있다. → `<meta name="robots" content="noindex,nofollow">`.
3. **지어낸 내용이 사실처럼 쓰여 있다**(사이트별 항목 참고). 샘플 바가 있어도 본문 문장이 "실제 후기"라고 단정하면 받는 사장님에게 역효과다.

### Major
4. **모바일 히어로(와 헤더) 좌우 여백이 0** — 또도스·블레싱·한솔. `.wrap{padding:0 20px}` 뒤에 `.hero-inner{padding:120px 0 64px}` 같은 축약 속성이 좌우 여백을 덮는다(todos:189·104, blessing:154·241, hansol hero-inner). 375px에서 제목·본문·버튼이 화면 끝에 닿는다. → 세로 여백만 `padding-block`으로.
5. **링크 미리보기 정보가 없다.** `description`·`og:title`·`og:description`·`og:image`·`theme-color` 없음, favicon은 빈 값. 카카오톡·문자로 보내면 썸네일 없이 주소만 뜬다.
6. **모바일에 메뉴가 없다.** 4개 모두 좁은 화면에서 메뉴를 숨기기만 한다. 9,800~13,300px(12~16화면) 길이를 스크롤로만 이동.
7. **앵커 이동 시 제목이 고정 바에 가려진다.** `scroll-margin-top` 없음. 또도스 모바일은 구획 첫 글자가 y=86인데 샘플 바가 133px까지 덮음. 로미는 72 / 94, 한솔 FAQ는 29 / 65.
8. **폼 제출 후 "접수되었습니다"** — 실제 전송은 없는데 완료 화면이 "연락드리겠습니다"라고 약속(todos:747, blessing:880, hansol:578, romi:627).
9. **제작 신청 버튼이 맨 아래에만 있다.** 상단 샘플 바에는 "제작: getsite.my" 링크뿐.
10. **모든 구획에 영문 대문자 머리말**(`01 — SPACE`, `CLASSES`, `WHY PRIVATE`, `PROGRAMS` …) — hallmark "Eyebrow on every section".
11. **마무리 구조가 4개 모두 같다**: 연락 카드 + 구글 폼 모양 신청서(색 띠) → "이 샘플이 마음에 드세요?" 배너 → 푸터. 히어로는 서로 달라 "색만 바꾼 같은 틀"은 아니다.

### Minor
12. 12~13.5px 글자가 사이트당 50~90곳. 13px 보조 글자 대비 미달이 겹친다.
13. `viewport-fit=cover`인데 하단 고정 버튼에 `safe-area-inset-bottom` 없음(한솔·로미).
14. 입력칸 `outline:none`, `:focus-visible` 규칙 없음(4개 모두).

## 확인하지 못한 것

- 실제 휴대폰, Safari, 카카오톡 인앱 브라우저.
- 480~760px 사이, 가로 모드, `prefers-reduced-motion`.
- 폼을 실제로 제출해 보지는 않았다(완료 문구는 소스로 확인).
- 로딩 속도·LCP 수치는 재지 않았다.
- 로미의 전화번호와 또도스의 인스타 계정이 실제 그 가게 것인지는 확인하지 않았다.

## 사용자가 정할 것

1. 고칠지 여부와 범위. 페이지 소스 위치를 알려 주면 고칠 수 있다(로컬 `getsite.my` 폴더에서는 찾지 못했다). 배포는 승인 후에만 한다.
2. 실제 가게 이름으로 된 예시 후기·이력·프로모션을 어디까지 둘지(삭제 / "예시" 표기).
3. 로미의 실제 전화번호를 샘플에 둘지.
